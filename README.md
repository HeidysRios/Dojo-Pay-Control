# Dojo Pay Control - Sistema de Control de Mensualidades y Pagos

Software de escritorio orientado a la gestión administrativa y control de cobranzas para academias deportivas / dojos. Desarrollado en **C#** con **Windows Forms** en **Visual Studio**, enfocado en agilizar el registro financiero de estudiantes con una interfaz de usuario limpia, accesible y estructurada para minimizar errores operativos.

## Funcionalidades Principales

### 1. Control de Acceso y Seguridad (Login)
* Módulo de autenticación visualmente centralizado para el personal administrativo autorizado.
* Validación de credenciales de usuario con protección de contraseñas.

### 2. Gestión y Registro de Pagos
* **Búsqueda y Selección de Estudiante:** Control de asignación de cuotas por alumno mediante listas desplegables.
* **Modalidades de Pago:** Selector dinámico entre pago de **Mensualidad** y **Anualidad**.
* **Detalle Temporal:** Registro paramétrico de mes, año lectivo y selector de fecha calendario.
* **Cálculo de Importes:** Visualización destacada en tarjeta de monto a pagar en Balboas (B/.).
* **Comprobantes:** Registro de métodos de pago y digitalización de número de recibo o comprobante físico para auditoría.

---

##  Enfoque de Diseño UI / UX
* **Jerarquía Visual Clara:** Organización por módulos semánticos (*Estudiante*, *Tipo de Pago*, *Detalles de Pago*) utilizando paneles y separadores para reducir la carga cognitiva del operador.
* **Paleta de Color Consistente:** Uso de tonos azul corporativo profundo y verdes de confirmación que transmiten orden financiero y seriedad administrativa.
* **Entrada de Datos Asistida:** Integración de componentes nativos (`ComboBox`, `DateTimePicker`, `NumericUpDown`) para evitar ingresos manuales erróneos.
